# 公司知识库首页

欢迎使用公司的 Obsidian 知识库。

这个知识库的定位是：
- Obsidian 负责存储、浏览、链接和沉淀长期知识。
- Codex 负责读取项目与知识库内容，并帮助整理、补写、生成模板化文档。

## 推荐使用方式
1. 用 Obsidian 打开整个 `obsidian-vault` 文件夹。
2. 从各目录下的 `_index.md` 进入对应业务主题。
3. 新任务先记录到 `09_Codex任务`。
4. 新产品先记录到 `03_产品开发`。
5. 新竞品先记录到 `04_竞品采集`。
6. 阶段性结论整理后，再沉淀到正式专题文档。

## 与 Codex 的协作方式
- 让 Codex 读取某个目录或某篇文档。
- 让 Codex 基于模板生成新文档。
- 让 Codex 汇总多个文档，输出周报、方案、产品结论或任务说明。
- 让 Codex 把任务型记录提炼成长期知识。

## 目录说明
- `00_公司战略`：方向、目标、阶段计划、核心决策。
- `01_Coupang业务`：平台运营、店铺策略、业务规则与经验。
- `02_4locks品牌`：品牌定位、视觉、品牌叙事、品牌资产。
- `03_产品开发`：产品立项、规格、卖点、开发进度。
- `04_竞品采集`：竞品分析、市场对比、差评问题、跟进结论。
- `05_客户问题库`：客户常见问题、售后问题、客服话术。
- `06_广告投放`：广告策略、投放记录、效果复盘。
- `07_供应链工厂`：工厂资料、供应链协作、打样与生产信息。
- `08_投资PPT`：融资材料、讲述逻辑、数据整理。
- `09_Codex任务`：给 Codex 的任务说明、产出记录、验收记录。
- `10_GEO系统`：GEO 相关需求、结构、数据与任务。
- `11_ERP系统`：ERP 相关需求、流程、字段与开发记录。
- `99_归档`：已过期但仍需要保留的内容。

## 维护建议
- 每个主题至少维护一个 `_index.md` 作为目录入口。
- 新文档尽量基于模板创建。
- 重要结论写清楚“结论”和“下一步”，避免只有过程没有结果。
